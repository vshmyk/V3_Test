# Abio Knowledge Base

This folder contains product/domain knowledge extracted from the public Abio Systems website for Abio NG replatforming context and future AI assistant retrieval.

Files:

- `AbioWebsiteKnowledge.md` - human-readable product/domain summary.
- `AbioWebsiteIndex.json` - machine-friendly search/index records by module, entity, workflow, keyword, and route.
- `LegacyTrainingMaterials.md` - human-readable index of module/menu help and report-training records from `ABIO_DEMO`.
- `LegacyTrainingMaterialsIndex.json` - machine-friendly index of legacy menu help, course links, report DataWindows, and report training text.

Use this KB for vocabulary, product positioning, module relationships, onboarding language, AI assistant grounding, and navigation hints.

The legacy training index is the most useful source for contextual in-app help because it maps modules, menu shortcuts, programs, windows, report DataWindows, microhelp, help URLs, and report-level training descriptions.

Do not use this KB as the source of truth for save logic, posting logic, payroll calculations, accounting rules, security permissions, or database behavior. Those must come from migrated PowerBuilder source, SQL Server schema/procedures, and approved requirements.
